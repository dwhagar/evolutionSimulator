# Changelog

All notable changes are recorded here, newest first, grouped by `MAJOR.minor` line. The build
number changes with every merge, so entries reference the line rather than each build. Each entry
carries the task ID(s) from [TODO.md](TODO.md) and links the PR. See [docs/versioning.md](docs/versioning.md).

## 0.1 — Data models for DNA and traits

### Added
- `INFRA.12`: Task labels are coloured by category, one colour family per area and shades for the items, with `needs-owner` bright red and a new `in-progress` label in royal blue. PRL
- `INFRA.11`: Python 3.12 or newer is required and checked everywhere it is stated (package metadata, linter target, workflows, README), with a clear error on an older Python. PRL
- `INFRA.9`: All Python source is under `src/`: the developer tools moved from `scripts/` to `src/evolution_tools/` (run with `python -m evolution_tools.NAME` or the PowerShell and batch wrappers in `scripts/`), and a test keeps it that way. [#235](https://github.com/dwhagar/evolutionSimulator/pull/235)
- `DNA.17`: Genome distance is one XOR and a bit count on a packed integer cached on each genome: 300 genomes' 44,850 pairs take 34 ms instead of 1,393 ms (about 41 times), with identical results. [#230](https://github.com/dwhagar/evolutionSimulator/pull/230)
- `UX.39`: The family tree: the Family tab opens a window with the selected animal, four generations of ancestors and three of descendants, dead ones included, each a button that selects it; the world keeps a bounded family book (the newest 20,000 dead) and saves are format 6. [#228](https://github.com/dwhagar/evolutionSimulator/pull/228)
- `SENSE.21`: Visibility: how easy a creature is to see depends on its size, its movement and a new `camouflage` gene (animal layout version 9); sight reaches farther for a more visible thing; camouflage costs upkeep and speed. Version 8 saves are refused. [#226](https://github.com/dwhagar/evolutionSimulator/pull/226)
- `DNA.16`: Research and design on gene interactions and balancing factors in real life, with proposals for the genome (`docs/research/gene-interactions-and-balance.md`, `docs/design/gene-balance.md`). [#227](https://github.com/dwhagar/evolutionSimulator/pull/227)
- `STORE.1`: Design note for the SQLite run file (`docs/design/storage.md`) with a storage benchmark script. [#224](https://github.com/dwhagar/evolutionSimulator/pull/224)
- `SPECIES.1`: A read-only species tracker in the core (`species.py`): groups the living by genome distance, keeps stable species ids with a parent, and ranks species by divergence from the founding genome, relative divergence or size. [#223](https://github.com/dwhagar/evolutionSimulator/pull/223)
- `INFRA.8`: Every task ID is a GitHub label with its own colour from a rotating palette (`src/evolution_tools/sync_labels.py`, `docs/labels.md`), and a `needs-owner` label and tag mark the items with an owner question still open. [#229](https://github.com/dwhagar/evolutionSimulator/pull/229)
- `SENSE.20`: Smell trails that fade: animals and corpses leave scent in a coarse grid (half-life 24 hours) that hunters and prey smell like any other source; off by default (`TraitRules.world.scent.enabled`), +6 to 10% per tick when on, no layout change. [#217](https://github.com/dwhagar/evolutionSimulator/pull/217)
- `UX.21`: Light, dark and follow-the-system themes, a keyboard shortcuts window (F1), an About box with the version and third-party notices, status tips on every menu action, and a test that every viewer widget has a parent. [#214](https://github.com/dwhagar/evolutionsimulator/pull/214)
- `UX.32`: Charts show the 10th to 90th percentile band for traits, a Lineages tab (founder lines still alive) and gene and trait names with units from the catalogue; the recorder keeps percentiles and lineage counts (history format 2, format 1 still loads). [#210](https://github.com/dwhagar/evolutionsimulator/pull/210)
- `UX.35`: Setup presets can be saved to and loaded from files, and a saved run can be copied with a new seed. [#208](https://github.com/dwhagar/evolutionsimulator/pull/208)
- `INFRA.6`: A viewer restart test no longer depends on timing. [#204](https://github.com/dwhagar/evolutionsimulator/pull/204)
- `UX.38`: The sense overlays use each animal's real sight, hearing, smell and touch ranges instead of working them out from its traits. [#202](https://github.com/dwhagar/evolutionsimulator/pull/202)
- `UX.37`: Closing the window on a world that was never saved asks whether to save it; panels can add their own close guard with `ViewerContext.add_close_guard`. [#198](https://github.com/dwhagar/evolutionsimulator/pull/198)
- `UX.15`: The brain and senses view: a Brain tab in the inspector with the animal's inputs and outputs as labelled bars and its network drawn with connection strengths and live values, and vision, hearing, smell and touch overlays on the world view. [#197](https://github.com/dwhagar/evolutionsimulator/pull/197)
- `UX.14`: The creature inspector: click an animal to see its body and state, its genes by group against the population average, and its family (parents, children, closest relatives), with Esc to deselect. [#195](https://github.com/dwhagar/evolutionsimulator/pull/195)
- `WORLD.17`: Two optional speed settings for the brain, `interval_scale` and `idle_interval_factor`, off by default so runs are unchanged; `interval_scale` 2 cuts a tick by about 23% at 300 animals and 3000 plants. [#193](https://github.com/dwhagar/evolutionsimulator/pull/193)
- `UX.36`: A plain launch now runs the real world in its own process: it opens the newest saved run, or starts the default founders with the New run panel open. `--fake` shows the made-up world, `--new` starts a new one and `--in-process` keeps it in the window's process. [#191](https://github.com/dwhagar/evolutionsimulator/pull/191)
- `UX.12`: The world view: pan and zoom, plants cached, animals as triangles along their heading (females notched, sleepers ringed, pregnant dotted), corpses, day and night ground, colour by diet, sex, energy, age or family, click to select, F to follow and a screenshot button; it asks the simulation for fewer frames when drawing is paused. [#187](https://github.com/dwhagar/evolutionsimulator/pull/187)
- `UX.33`: The window runs the simulation in its own process (`--world`): it says "Starting the simulation" until the host is ready, shows a warning with the traceback and a Restart button if the simulation crashes, and saves and resumes runs through the process. A viewer that stops reading can no longer freeze the simulation (the host sends from a thread). [#188](https://github.com/dwhagar/evolutionsimulator/pull/188)
- `WORLD.14`: Faster ticks again, with identical results for one seed: night learning shares the hidden layer, the daylight lookup runs once a tick and sensing reuses reach; about 8-9% per tick (38.4 to 35.2 ms at 300 animals and 3000 plants). [#178](https://github.com/dwhagar/evolutionsimulator/pull/178), [#184](https://github.com/dwhagar/evolutionsimulator/pull/184)
- `UX.17`: The setup screen: File > New run with presets, animal and plant counts, a seed, a name and a searchable form of every tuning value generated from the config, which saves the new run as soon as it starts. Also fixed events being lost after the first poll in the viewer's local backend. [#183](https://github.com/dwhagar/evolutionSimulator/pull/183)
- `UX.31`: The simulation process now records history and can run a saved run: it streams the statistics to the window in batches, saves checkpoints on its own and on request, and resumes a run from a checkpoint. [#181](https://github.com/dwhagar/evolutionSimulator/pull/181)
- `TRAIT.11`: Attack, corpse and world rules (grazing, mating reach, birth scatter, calls) move into the one `TraitRules` tree, so a run's whole tuning is one object (behaviour unchanged; saved worlds are upgraded to format 5). [#179](https://github.com/dwhagar/evolutionSimulator/pull/179)
- `UX.18`: Saved runs in the viewer: save the current run, list saved runs with their size and a population line, resume, delete, export history as CSV, open a read-only history window with the charts and checkpoints, and a warning when runs take more than 5 GB. [#173](https://github.com/dwhagar/evolutionSimulator/pull/173)
- `UX.19`: A Windows package: a PyInstaller folder build zipped by a workflow that is started by hand (CI stays weekly), with the Qt license notices and a README download section; built and self-tested on Linux, to be tried on Windows by the owner. [#175](https://github.com/dwhagar/evolutionSimulator/pull/175)
- `UX.30`: Family colour numbers for every animal (two values from the genome, close for relatives) in the frame, so the world view can colour by family (frame format 2). [#171](https://github.com/dwhagar/evolutionSimulator/pull/171)

- `WORLD.11`: Plants can reach full size and seed again: soil limits count only neighbours, and founder plants that could not pay their own upkeep are redrawn, so plant populations now settle at hundreds to thousands instead of dying out.
